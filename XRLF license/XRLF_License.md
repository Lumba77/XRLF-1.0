# XRLF License

XRLF License Model - Full Draft (Conservative Adoption Strategy)

## 
1. Base License
XRLF is distributed under the Apache License, Version 2.0 ("Apache 2.0"), a permissive opensource license that allows broad use, modification, and distribution. Apache 2.0 applies to:
- XRLF specification documents
- XRLF container format definitions
- XRLF runtime protocol definitions
- XRLF adapter API definitions
- XRLF compliance test definitions
- XRLF reference implementations
- XRLF documentation Apache 2.0 ensures maximum adoption and compatibility across the open-source ecosystem.

## 
2. XRLF Commercial Use Exception
To ensure sustainability while maintaining openness, XRLF includes an additional clause: The XRLF Commercial Use Exception ("The Exception").

## 
2.1 Applicability
The Exception applies to:
- XRLF runtime implementations
- XRLF-compliant adapters
- XRLF-compliant multimodal gateways
- XRLF-compliant container generators
- XRLF-compliant inference servers
- XRLF-compliant tooling

## 
2.2 Free Use
XRLF is free to use for:

 Individuals
- Students
- Researchers
- Open-source contributors
- Non-profit organizations
- Indie developers
- Startups with annual revenue under 500,000
- Small companies under 500,000 annual revenue These groups may:
- Use XRLF in any project
- Modify XRLF
- Distribute XRLF
- Build XRLF-compatible tools
- Sell XRLF-based products
- Publish XRLF-based research No commercial license is required.

## 
3. Commercial License Requirement
Companies with annual revenue equal to or exceeding 500,000 must obtain a Commercial XRLF License to:
- Use XRLF in production
- Integrate XRLF into proprietary systems
- Redistribute XRLF-compliant runtimes
- Offer XRLF-based cloud services
- Sell XRLF-compatible products
- Bundle XRLF with commercial software
- Use XRLF branding in enterprise contexts This requirement ensures that XRLF remains sustainable while staying open for the entire community.

## 
6. Redistribution Rules
Redistribution of XRLF source code or binaries is allowed under Apache 2.

## 0. However, redistribution of XRLF-compliant runtimes by companies above the revenue threshold requires a commercial license. This ensures:
- Open-source forks remain free
- Community tools remain free
- Enterprise distributions contribute financially

## 
7. Proprietary Extensions
Companies may create proprietary XRLF extensions. However:
- They must not claim to be "XRLF-compliant" without passing the compliance suite
- They must not use XRLF trademarks without a commercial license
- They must not distribute XRLF runtime components without a commercial license This protects the integrity of the protocol.

## 
8. Compliance Requirements
To be considered "XRLF-compliant," an implementation must pass:
- The XRLF container format tests
- The XRLF runtime behavior tests
- The XRLF adapter API tests
- The XRLF multimodal gateway tests The compliance suite will be published separately in XRLF_COMPLIANCE.md. You can continue with XRLF compliance tests.
